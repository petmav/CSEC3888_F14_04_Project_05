# CSEC3888 — CS Capstone Project (F14-04)

Working repo for the Sydney Uni CS Capstone unit (COMP3888/COMP3988/ISYS3888/CSEC3888/SOFT3888/COMP5615), Semester 2 2026.

## Structure

Each week of semester has its own folder, following the Canvas Unit Schedule:

```
Week-01/
  references/   <- assignment templates, contracts, and other files published on Canvas for that week
  submission/   <- this group's actual artefacts submitted for that week
Week-02/
  references/
  submission/
...
Week-13/
  references/
  submission/
```

- `references/` holds templates and reference documents downloaded from Canvas for that week (group contract, deed poll, report/presentation templates, meeting minutes template, etc).
- `submission/` holds the group's finished artefacts for that week — the actual filled-in report, slides, meeting minutes, etc, that get uploaded to Canvas.
- The weekly meeting minutes template is required every week from Week 2 onward, so a copy is included in each week's `references/` folder.
- Not every week has published templates yet — Canvas releases some assignment content closer to the due date. Each week's `README.md` notes what's currently available and what's still pending.
